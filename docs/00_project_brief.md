## 一句话

基于 NASA C-MAPSS 完成 RUL 预测，将推理部署到 C++/ONNX，并用 llama.cpp 本地 LLM 解释结构化诊断结果。

## 问题陈述

工业设备维护若只做「坏了再修」，成本高、停机风险大。预测性维护希望用连续传感器时间序列估计剩余寿命（RUL）与风险等级。公开 benchmark（C-MAPSS）可复现、可量化；端侧部署与本地解释则对应真实离线/工控场景。

## 目标交付

1. 可复现的数据处理与 RUL baseline（至少一种经典 ML）
2. 至少一种序列深度学习模型，并与 baseline 对比
3. C++ 端侧推理链路（CSV → 特征 → ONNX → RUL/风险）
4. llama.cpp 解释层（结构化 JSON → 自然语言建议）
5. 完整文档：决策、实验、试错、心路、Gate 审核链
