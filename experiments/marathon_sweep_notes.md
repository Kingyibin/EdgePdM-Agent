# 马拉松超参扫描（结项后旁证）

> 性质：**结项后探索 / 消融旁证**，不是 G3–G6 正式交付替换。  
> 脚本：`training_marathon.py`（本机长跑扫描服务）  
> 日期跨度：结项后闲时训练（记录入库日 2026-08-20）

## 故事一句话

正式链路已经用七月 LSTM（RMSE≈14.27）打通 ONNX/C++/LLM；闲时又在**同一任务**上做真实超参扫描，证明结果对窗口、隐层、层数、学习率、种子敏感，并补上 MC Dropout 不确定性。

## 扫描设定

每轮 12 组配置轮流真训（非模拟），维度包括：

| 维度 | 取值示例 |
|------|----------|
| window | 15 / 20 / 25 / 30 / 35 / 40 |
| hidden | 48 / 64 / 72 / 80 / 96 |
| num_layers | 1 / 2 / 3 |
| lr | 1e-3 / 5e-4 / 2e-3 |
| seed | 每轮更换 |

单次实验默认约 18 epoch（短于正式 G3 的 25 epoch）。  
每个目录仅写 `metrics.json`（**不存 `.pt`**）；复现最优配置需按 `cfg` 重训。

## 目录怎么读

| 前缀 | 含义 |
|------|------|
| `r01_`～`r03_` | 完整轮次（主旁证） |
| `r05_`～`r07_` | 上一会话崩溃残留；rotate 未清干净，**不影响结论**，可择机删除 |
| `exp_*` | 七月正式实验（含权重 / C++ / LLM），**简历主数字仍看这里** |

## 关键真实数字（抽查与排行）

抽查 `r03_w30_h64`（与正式配置同结构，不同 seed）：

- RMSE(capped125) ≈ **15.29**，MAE ≈ **11.14**
- beat XGBoost 17.48 = true
- MC Dropout coverage95 ≈ **0.67**，mean σ ≈ **6.99**
- elapsed ≈ **70.7 s**

全库排行（71 个 `r*`，按 RMSE）：

| 名次 | 目录 | RMSE | NASA Score | 备注 |
|------|------|------|------------|------|
| 1 | `r01_w30_h64_lr5e4` | **13.10** | **240.8** | 扫描最优；**未**导出 ONNX |
| — | `r01_w30_h64` | 13.37 | 284.4 | 同结构不同 seed 也可更好 |
| — | `r03_w30_h64` | 15.29 | 548.4 | 同结构可变差 → 种子敏感 |
| 正式 | `exp_20260722_lstm_fd001` | **14.27** | **324.6** | 有 `lstm.pt` + 端侧对齐 |

打赢 XGBoost：约 **67 / 71**。

## 决策口径（写进故事时必须遵守）

1. 简历主数字仍用正式 LSTM **14.27**（可复现权重 + C++ 对齐）。  
2. 扫描最优 **13.10** 只能写作「后续消融旁证」，除非另立 G7：重训存权 → ONNX → C++ 复验。  
3. 马拉松说明「不是只跑一次运气好」，也说明「短训预算 / 种子」会晃动指标。

相关决策：`docs/02_decision_record.md` ADR-009。
